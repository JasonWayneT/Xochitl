# BMAD Init

**Goal:** Bootstrap the `_bmad/` structure that all BMAD skills require in the current
project. Safe to re-run — never overwrites existing config.

## Conventions

- `{project-root}` = current working directory (absolute path).
- `{skill-root}` = this skill's installed directory.
- The resolver script lives at `{skill-root}/../../scripts/resolve_customization.py`
  (two levels up from the skill dir, into `.xochitl/scripts/`).

## On Activation

Check whether `{project-root}/_bmad/` already exists.

If it does and contains `bmm/config.yaml` and `scripts/resolve_customization.py`,
report that BMAD is already initialized and show the current config values. Stop.

Otherwise continue with the steps below.

## Step 1: Derive project context

- `{project-name}` = basename of the current working directory.
- `{xochitl-scripts}` = `{skill-root}/../../scripts/` (resolved as absolute path).

Verify that `{xochitl-scripts}/resolve_customization.py` exists before proceeding.
If it does not exist, report:

> "ERROR: resolve_customization.py not found at `{xochitl-scripts}`. The Xochitl
> installation may be incomplete. Cannot initialize BMAD."

Then HALT.

## Step 2: Create directories

Create the following if they do not exist:

```
{project-root}/_bmad/
{project-root}/_bmad/bmm/
{project-root}/_bmad/_config/
{project-root}/_bmad/scripts/
{project-root}/_bmad/custom/
{project-root}/_bmad-output/
{project-root}/_bmad-output/planning-artifacts/
{project-root}/_bmad-output/implementation-artifacts/
```

## Step 3: Write config

Create `{project-root}/_bmad/bmm/config.yaml` only if it does not already exist.
Never overwrite. Substitute actual resolved values for `{project-name}` and
`{project-root}` — write literal strings, not template variables.

```yaml
# BMAD Project Configuration — generated by bmad-init
# Edit freely. Re-running bmad-init will not overwrite this file.

project_name: {project-name}
user_skill_level: intermediate
planning_artifacts: "{project-root}/_bmad-output/planning-artifacts"
implementation_artifacts: "{project-root}/_bmad-output/implementation-artifacts"
project_knowledge: "{project-root}/docs"

user_name: Jason
communication_language: English
document_output_language: English
output_folder: "{project-root}/_bmad-output"
```

## Step 4: Deploy resolver script

Copy `{xochitl-scripts}/resolve_customization.py` to
`{project-root}/_bmad/scripts/resolve_customization.py`.

Skip if the destination already exists and is non-empty.

## Step 5: Report

Show exactly what was created vs. already existed:

```
BMAD initialized in {project-root}

  _bmad/bmm/config.yaml              [created | already existed]
  _bmad/scripts/resolve_customization.py  [copied | already existed]
  _bmad/custom/                      [created | already existed]
  _bmad-output/planning-artifacts/   [created | already existed]
  _bmad-output/implementation-artifacts/  [created | already existed]

Ready. Run any BMAD skill — configuration and customization will resolve correctly.
To customize a skill, place overrides in _bmad/custom/{skill-name}.toml (team)
or _bmad/custom/{skill-name}.user.toml (personal, gitignore this one).
```
